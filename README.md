# TP Integrador API REST Librería ‑ Spring Boot

## Descripción
Trabajo práctico integrador de una API REST para la gestión de una librería, desarrollado con Java y Spring Boot. El sistema permite administrar libros, socios y préstamos, cumpliendo con la consigna del trabajo práctico.

## Tecnologías utilizadas
‑ Java 17
‑ Spring Boot
‑ Maven
‑ H2 Database (base de datos en memoria)
‑ Postman (prueba de endpoints)
‑ Git + GitHub (control de versiones)

## Estructura del proyecto
1. **Controladores**: Reciben las peticiones HTTP
2. **Servicios**: Lógica de negocio
3. **Repositorios**: Acceso a la base de datos
4. **Entidades**: Modelos (Libro, Socio, Préstamo)

## Cómo levantar la API
1. Abrir el proyecto en VS Code
2. Ejecutar la clase principal de Spring Boot
3. La API corre en `http://localhost:8080`

##  Prueba de endpoints (Postman)
Se pueden probar las operaciones CRUD para:
Libros
Socios
Préstamos
