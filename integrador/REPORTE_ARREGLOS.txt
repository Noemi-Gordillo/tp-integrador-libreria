3. ERRORES DE COMPILACION CORREGIDOS POR ARCHIVO
--------------------------------------------------------------------------------

>> Libro.java
   - Todos los campos eran "final" sin constructor vacio: Jackson no
     podía deserializar JSON (POST/PUT fallaban).
   - Faltaban setters para todos los campos.
   - Se agregaron: constructor vacio, setters, y campos no-final.
   - Se agrego constructor de 6 argumentos (disponible=true por defecto)
     para compatibilidad con IntegradorApplication.java.

>> LibroRepository.java (interfaz)
   - Faltaban los métodos: listarTodos(), listarDisponible(), borrar(Long).
   - El controlador los usaba pero la interfaz no los declaraba
     (error de compilación).

>> LibroRepositoryImp.java
   - Faltaba implementar: listarTodos(), listarDisponible(), borrar(Long).
   - Se migraron desde el archivo roto LibroRepositorylmpl.

>> Prestamo.java
   - setld() (con L minuscula) -> setId() (typo en nombre de metodo).
   - getSocio() devolvia Long pero el nombre sugeria un objeto Socio,
     se renombro a getSocioId() para consistencia.
   - Faltaba constructor vacio para deserializacion JSON.

>> PrestamoControlador.java
   - Import incorrecto: org.springframework.web.annotation.RequestBody
     -> org.springframework.web.bind.annotation.RequestBody
   - Faltaban imports: @PatchMapping, @PathVariable, @RequestMapping.
   - Variable "PrestamoCreado" (mayuscula) -> "prestamoCreado" (typo).
   - Se agregaron GET /api/prestamos y GET /api/prestamos/{id}
     que no existian.

>> PrestamoRepository.java (interfaz)
   - Faltaba declarar el metodo listarTodos().

>> PrestamoRepositoryEnDBImp.java
   - p.getSocio().getId() no compilaba: getSocio() devuelve Long,
     no un objeto. Corregido a p.getSocioId().equals(...).
   - Se implemento listarTodos().

>> PrestamoServicio.java  (el más roto del proyecto)
   - "import ar.edu.undec.integrador" en lugar de "package" (error
     critico de declaración de paquete).
   - getSocio().getId -> getSocioId() (getSocio no existe, el campo
     es socioId de tipo Long).
   - getLibro().getId -> getLibroId() (idem anterior).
   - "RuntimeExeption" (typo) -> RuntimeException.
   - "pretamo" (typo) -> "prestamo".
   - "estadoPrestamo.DEVUELTO" (minuscula) -> EstadoPrestamo.DEVUELTO.
   - En renovarPrestamo(): variable "prestamo" usada sin declarar.
   - Se agregaron métodos: listarTodos(), buscarPorId().

>> SocioControlador.java
   - Import "anotation" -> "annotation" (typo en paquete de Spring).
   - "prestamosServicio" -> "prestamoServicio" (nombre incorrecto).
   - "@PathVaribe" -> "@PathVariable" (typo).
   - "HttpStatus.NOT-FOUND" -> "HttpStatus.NOT_FOUND" (guion vs guion bajo).
   - "socioExitente" -> "socioExistente" (typo).
   - "ResponseEntity.Status" -> "ResponseEntity.status" (mayuscula incorrecta).
   - Se agregó GET /api/socios (listar todos) que no existía.

>> Socio.java
   - Faltaban: constructor vacio, setNombre(), setEmail(), setId().
     Sin estos el controlador PUT no podía modificar nada.

>> SocioRepository.java (interfaz)
   - Faltaba declarar borrar(Long id): la implementación tenía @Override
     pero la interfaz no lo declaraba (error de compilación).
   - Se agregó listarTodos().

>> SocioRepositoryEnDBImp.java
   - Se implementó listarTodos().

>> TurnoRepository.java (interfaz)
   - Se agregó listarTodos().

>> TurnoRepositoryImp.java

>> TurnoRepositoryEnDBImp.java
