📚 API Biblioteca — Rutas interactivas

Spring Boot 4.1.0 · Java 21 · H2 in-memory

Base URL: http://localhost:8080 Content-Type: application/json 🗄️ Abrir H2 Console
✅ Cómo usar: expandí cualquier endpoint y hacé clic en ▶ Probar para ejecutarlo contra el backend en localhost:8080. Para POST/PUT podés editar el body antes de enviarlo.
